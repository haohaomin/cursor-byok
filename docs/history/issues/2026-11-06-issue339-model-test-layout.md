## 复现与修复

820×558，切换英文，按供应商展开第一个模型。测试前编辑按钮位于 `(595.25, 148.75)`，测试完成后变为 `(296.25, 187)`；徽标插入同一个 flex 行后，使按钮组换行。葡萄牙语也复现，中文单独测试不能暴露这个缺口。

将每行明确分成两列、两行，保留结果所需高度：

```text
┌──────────────────────────┬────────────────────────────────┐
│ 模型名称                 │ 测试 / 编辑 / 复制 / 删除       │
│ 模型 ID                  │ 等待 / 成功 / 失败 / 取消结果   │
└──────────────────────────┴────────────────────────────────┘
```

空闲时结果区域留空，名称、ID 和操作按钮保持原位置。名称及 ID 可收缩并显示省略号，`title` 保留完整文本。测试按钮自身由“测试”变为“取消测试”时文字宽度可以变化，其右侧其他按钮不移动。

```text
apps/desktop/src/features/models/
├── CursorModelCards.tsx           # 318 行：内置模型及共用插件模型行的内容位置
├── CursorSettings.module.scss    # 374 行：两行布局、保留结果高度及文本省略
└── CursorModelTestResult.tsx      # 未改：显示现有测试状态和详情提示

用户点击测试 → 现有页面状态与 API → 等待/成功/失败/取消
                                     ↓
                         固定结果区域更新，操作按钮保持位置
```

行数为实测，包含注释和空行，不含测试与生成代码。删除旧的 `modelRowName` 包装及其 flex 换行约束；没有新增模块。内置和插件模型行共用同一布局，插件测试只使用合成描述符，不涉及插件功能、账号或生命周期实现。
