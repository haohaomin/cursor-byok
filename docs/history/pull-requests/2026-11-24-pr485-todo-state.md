## 复现与采用范围

本轮选择采用 Todo 展示投影部分，基于 fork `70c3cd3`（#444 已合并）。新增真实 RunSSE/KV/checkpoint 回归，在原实现上失败：两项待办只更新其中一项的状态，`UpdateTodosSuccess.todos` 长度变为 1，预期是 2。未修改的事项被完成回包遗漏，更新项的正文与依赖也可能缺失。

旧实现直接把本次 patch 填入 args 和 result。采用原 PR 的前后状态对照逻辑：完成卡片的 args 带更新前的列表，result 带合并后的完整列表；复用现有 `apply_todo_write`，保留原 Todo 参数和模型结果。与原 PR 的每轮预加载不同，本实现只在出现 Todo 完成回包时读取 Todo Blob，并结合结果提交前那个不可变检查点的 canonical 历史初始化。客户端未附带 Cursor 检查点时，新 Run 从所选历史对应的服务器检查点恢复 Todo 引用，再启动检查点输出；压缩已经移除旧工具调用时也能保留待办。

该 PR 的子代理准入与账号路由、DeepSeek 协议续写、文档构建说明不在本次候选内，清单按分项处理，不能标成整个 PR 已采用。
